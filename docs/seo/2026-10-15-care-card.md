# Printable shoe-care card

Created October 15, 2026. Local publication candidate; root owns the website link, merge and deployed readback.

The one-page A4 card is `public/downloads/yikat-ayakkabi-bakim-karti.pdf`. It uses the existing owner PNG logo, navy `#042C53`, Bricolage Grotesque and a generous white page. All visible text is at least 10pt; body copy is 10.5-11.5pt. No customer images, generated illustrations, fictional cases, new price or turnaround promises are included.

## Content and source boundaries

The card starts with the individual model's care instructions, then separates fabric/mesh sneakers, smooth leather and suede/nubuck. It includes the owner's no-washing-machine/no-dryer policy, natural drying, and practical stop conditions for colour transfer, peeling or sole separation. It contains no home chemical recipe, disinfection promise or repair claim.

- [Clarks Shoe Care Guide](https://clarks.com.au/pages/shoe-care-guide), read October 15: soft tools for leather, gentle cleaning without oversaturation for trainers, specialist suede/nubuck brushes and drying without artificial heat. The site's separate machine-washable children's-shoe exception is not presented as Yıkat policy. The card's universal no-machine recommendation is Kaan's explicit editorial instruction.
- [Nike sneaker washing guidance](https://www.nike.com/a/can-you-put-shoes-in-the-washer), read October 15, supports the linked machine-care reference. Both manufacturer sources are clickable in the PDF. These are general consumer references, not a claim that either manufacturer endorses the shop.
- Address, phone and hours are read from `lib/site.ts` on every generation. Unicode dashes are normalized to ASCII for PDF compatibility; numbers and content remain unchanged.
- The care QR and linked short address point to `https://www.yikat.tech/rehber`. A separate Google review QR lives in the private operations workstream and is intentionally absent from this care card.

## Reproduce

Install the pinned package list in a Python environment, then run:

```sh
python -m pip install -r scripts/assets/care-card/requirements.txt
python scripts/generate-care-card.py
pdftoppm -png -scale-to 1800 -singlefile public/downloads/yikat-ayakkabi-bakim-karti.pdf scripts/assets/care-card/qa-preview
```

The current session used `/Users/emrebenian/Desktop/STARTUPS/YIKAT/workstreams/search-growth-20261015/.venv/bin/python`. The generator works from any current directory. It performs no network requests and reads the checked-in font source, original logo and current site facts. It uses ReportLab invariant output and verifies the font-source hash, page count, extracted Turkish text, expected links and three distinct embedded font faces.

The font source was downloaded from the official `google/fonts` repository. `scripts/assets/care-card/font-source.json` records URLs and hashes; the original OFL license is retained beside the font. Static instances for weights 400/600/700, width100 and optical size14 are generated in memory. They have distinct internal names so ReportLab cannot silently substitute one weight for another. No static derivative font files are distributed separately.
