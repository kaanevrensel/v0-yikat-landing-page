# Before/after photos

Shop photos taken at the Bakırköy counter when each pair arrived and when the work was done. Each pair is published on a recorded decision: the customer's written permission in the Yıkat panel or a founder's publication decision. A pair is removed on request (destek@yikat.tech). Derivatives: colour converted to sRGB, cropped to 4:3 (a few photos first trimmed at one edge), resized to 1200×900, WebP, all metadata removed. No retouching.
